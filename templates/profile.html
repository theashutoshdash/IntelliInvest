Module 4 · Investor Segmentation K-Means · 3 Clusters
Unsupervised · 5 Features
K-Means clustering minimises inertia (within-cluster sum of squares) across 3 clusters using 10 random initialisations. Input features are standard-scaled before fitting. Cluster labels are assigned by sorting centroids on mean age, producing consistent Conservative / Moderate / Aggressive segmentation. The assigned segment is surfaced automatically on the Dashboard Profiler.
